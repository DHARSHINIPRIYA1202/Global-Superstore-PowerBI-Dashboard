 📊 Global Superstore Sales & Profit Analysis Dashboard

 📌 Project Overview

This project presents an interactive **Sales & Profit Analysis Dashboard** created using **Microsoft Power BI** with the **Global Superstore** dataset.

The project follows a complete data analytics workflow:

**Raw Data → Data Cleaning → Data Transformation → Data Analysis → Dashboard → Business Insights**

The dashboard analyzes sales, profit, profit margin, product categories, regions, markets, and shipping performance to provide meaningful business insights and support data-driven decision-making.



🛠️ Tools & Technologies

* **Microsoft Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and KPIs
* **Microsoft Excel** – Raw and cleaned data
* **GitHub** – Project documentation and portfolio


### 📂 Project Files

* `Global_Superstore_Dashboard.pbix` — Power BI dashboard
* `Global Superstore Data.xlsx` — Dataset
* `Screenshots/` — Dashboard previews

🎓 Project Purpose

This project was developed as a **Data Analytics and Business Intelligence portfolio project** to demonstrate the ability to transform raw business data into a clean dataset, analyze business performance, and communicate insights through an interactive Power BI dashboard.

The project demonstrates the complete process from **data preparation to business decision-making**.
